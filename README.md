# JavaScript Amazon Clone

A vanilla JavaScript e-commerce clone built to practice storefront interfaces and customer flows without a frontend framework.

## Included flows

- Product browsing and catalog data
- Cart and checkout pages
- Orders and delivery tracking views
- Reusable styles, images, and browser scripts
- Tests for key storefront behavior

Open `amazon.html` with a local static server to explore the project. Some features may depend on the included backend or local data configuration.
